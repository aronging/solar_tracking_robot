# solar_tracking_robot
MXET 345 Lab Final Project

Two-axis solar tracker on the MXET 345 lab robot.

- `Code/`: tracker software (Python, Raspberry Pi 4). Start with [`Code/README.md`](Code/README.md).
- `CAD/`: STEP models and test-print STLs for the pan/tilt mount.
- `mxet345-solar-tracker-*.md`: project plan, build plan, BOM, breakdown and software spec.
- `Hardware List & Assembly Guide.pdf`: mechanical assembly reference.
- `Lab Ex - *`, `MXET 345_Final Project_V1*`, `MXET 345 Final Project Overview.md`: course documents.
