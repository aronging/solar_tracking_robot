# solar_tracking_robot
MXET 345 Lab Final Project: a two-axis solar tracker (pan-tilt panel mount) on the MXET 345 lab robot, driven by the robot's Raspberry Pi.

**Start here: [`Code/README.md`](Code/README.md) (setup and run, step by step).**

- `Code/`: tracker software (Python, Raspberry Pi). Open this folder in VS Code (Remote-SSH on the Pi).
- `CAD/`: current STEP parts and `Solar Tracker Assembly.step` (Nov 17); `Purchased Parts/`, `Test Prints/` and `_superseded/` (old revisions).
- `docs/`: project documents.
  - [`Design Overview.md`](docs/Design%20Overview.md): what the system does, the algorithm, conventions, numerical methods, test plan and open items.
  - [`Hardware & BOM.md`](docs/Hardware%20%26%20BOM.md): wiring, I2C map, parts and costs.
  - [`Electrical Assembly Guide.md`](docs/Electrical%20Assembly%20Guide.md): panel sensor and servo wiring, step by step (PDF copy alongside).
  - [`Course Requirements.md`](docs/Course%20Requirements.md): grading, deliverables, team roles and the lab robot.
  - `Hardware List & Assembly Guide.pdf`: mechanical assembly reference (re-exported Nov 17 from the live guide).
  - `Solar Tracker – Numerical Methods Summary.docx`: one-page list of the numerical methods.
  - `Course Requirements.docx`, `Design Overview.docx`, `Hardware & BOM.docx`, `README.docx`: Word exports of older versions of the documents above.
