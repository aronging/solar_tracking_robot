## General Guidelines

1. **Application Selection**
   Each team must select a project topic that requires substantial use of numerical methods for problem-solving. The chosen application should clearly demonstrate how numerical techniques are essential to achieving the project objectives, rather than being used only superficially.

2. **Hardware Implementation**
   The project must include a physical hardware component. Teams may use the mobile robot platform provided in the laboratory or develop their own hardware system. The integration between hardware and computational methods should be clearly demonstrated.

3. **Numerical Methods and Analysis**
   Both the final demonstration and the written report must include a dedicated section that:
   - Clearly explains the numerical method(s) used in the project
   - Identifies where and how these methods are implemented in the code
   - Provides a detailed analysis of algorithm performance, including convergence behavior, stability, and accuracy
   - Includes supporting data, plots, or experiments to validate the effectiveness of the numerical approach

## Grading Criteria

Projects will be evaluated based on the following factors:

1. **Complexity of the Problem and System Design**
   The level of technical challenge, including the sophistication of the numerical methods and system integration.

2. **Robustness and Accuracy**
   The reliability and performance of the system under different conditions, as well as the correctness of the results.

3. **Report, Documentation, and Analysis**
   The clarity, completeness, and professionalism of the written report, including technical explanations, code documentation, and data analysis.

4. **Creativity and Innovation**
   The originality of the idea, design approach, and implementation.

## Team Structure

- Each team should consist of **3–4 students**.

## Deadlines

1. **Project Proposal**
   Each team must submit a proposal outlining:
   - Project title and objectives
   - Description of the hardware system
   - Numerical methods to be used
   - Expected outcomes and potential challenges

2. Final Project Submission

   A report; Slides PPT for the presentation.

## Example Project

**Drawing Robot System**

- Utilize the mobile robot platform provided in the lab.
- Attach a two-link robotic arm, with motors installed at each joint.
- Mount a pen at the end-effector of the arm.
- Plan a trajectory for the pen tip to draw shapes, letters, or patterns.
- Use numerical methods (e.g., inverse kinematics, interpolation, or trajectory optimization) to:
  - Compute joint angles at each time step
  - Determine the motion of the mobile robot base
- Demonstrate coordinated control of the robot and arm to produce accurate drawings.

This project highlights the integration of **numerical methods, control, and hardware implementation**, as well as analysis of trajectory accuracy and convergence.
